# Replacing the PM Sensors

Follow these steps to replace the PM Sensors. This guide assumes you have HDPE enclosure.

!!! example "Step-by-step"
    * Open the enclosure

    <img src="/assets/images/replacing-the-particulate-matter-sensor-pms.jpg" width="2000" height="1333" alt="Replacing the Particulate Matter Sensor (PMS)">
    
    * Remove power from the sensors (both, USB and battery)

    <img src="/assets/images/replacing-the-particulate-matter-sensor-pms-2.jpg" width="2000" height="1333" alt="Replacing the Particulate Matter Sensor (PMS)">

    <img src="/assets/images/replacing-the-particulate-matter-sensor-pms-3.jpg" width="2000" height="1333" alt="Replacing the Particulate Matter Sensor (PMS)">

    * Extract the SCK and PM sensors by removing the screws

    <img src="/assets/images/replacing-the-particulate-matter-sensor-pms-4.jpg" width="2000" height="1333" alt="Replacing the Particulate Matter Sensor (PMS)">

    <img src="/assets/images/replacing-the-particulate-matter-sensor-pms-5.jpg" width="2000" height="1333" alt="Replacing the Particulate Matter Sensor (PMS)">

    * Disconnect the 6-way cable from the PM sensor

    <img src="/assets/images/replacing-the-particulate-matter-sensor-pms-6.jpg" width="2000" height="1333" alt="Replacing the Particulate Matter Sensor (PMS)">

    <img src="/assets/images/replacing-the-particulate-matter-sensor-pms-7.jpg" width="2000" height="1333" alt="Replacing the Particulate Matter Sensor (PMS)">

    * Extract the PM sensor and replace it with the new one

    <img src="/assets/images/replacing-the-particulate-matter-sensor-pms-8.jpg" width="2000" height="1333" alt="Replacing the Particulate Matter Sensor (PMS)">

    <img src="/assets/images/replacing-the-particulate-matter-sensor-pms-9.jpg" width="2000" height="1333" alt="Replacing the Particulate Matter Sensor (PMS)">

    * Connect back the 6-way cable and put the sticker from the previous sensor on the PM sensor (this ID is related to the Data Board)

    <img src="/assets/images/replacing-the-particulate-matter-sensor-pms-10.jpg" width="2000" height="1333" alt="Replacing the Particulate Matter Sensor (PMS)">

    <img src="/assets/images/replacing-the-particulate-matter-sensor-pms-11.jpg" width="2000" height="1333" alt="Replacing the Particulate Matter Sensor (PMS)">
    
    * Put everything back together. No need to update anything else in the SCK. You are good to go!
